# 双向钢人论证

忠实呈现两个方向的最强理由，再根据证据和用户取舍做判断，不制造虚假的势均力敌。

## 第一轮：论证与关键问题

1. 识别两个选项、目标和约束，以中性语言重述真正的选择。若材料并非二选一，先界定要比较的两条主要路径，说明被暂时放在范围之外的选择。
2. 分别陈述每个方向最强的依据、适用条件、最好收益、最大风险，以及最难回应的反对理由。不要把自己不喜欢的一方写成稻草人，也不为证据不足的一方编造支持。
3. 找出双方真正分歧、能改变选择的关键变量，以及目前缺少的信息。
4. 只提出一个最可能改变结论的问题，等待用户回答。问题之前不提前宣布最终推荐。

## 第二轮：形成判断

结合用户回答给出清楚的倾向、理由、适用条件和下一步行动。若关键证据仍不足，则给条件式结论及最有信息价值的验证动作，不强作确定判断。

用户明确要求只用现有材料、不要追问时，跳过等待，标明假设并给出条件式判断。

## 输出

第一轮：选择重述 → 双方论证对照 → 决定性分歧 → 一个问题。

回答之后：推荐方向 → 判断依据 → 什么变化会使推荐反转 → 下一步。

## 示例

用户：“创业还是继续上班？请先做双向钢人分析。”

不要假设用户追求最高收入，也不要以“创业勇敢、上班保守”代替论证。先比较目标和约束，选一个决定性的未知量提问。

## 完成检查

双方是否得到诚实而有力的呈现？证据强弱是否被保留？首轮是否只问一题并等待？最终建议是否明确说明反转条件？
